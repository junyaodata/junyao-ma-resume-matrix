# Portfolio Demo Script

## Opening — 30 Seconds

This repository is my resume operating system. It contains one comprehensive master resume, the evidence and project materials behind it, and targeted one-page versions for different role families.

## Master Resume — 60 Seconds

The master version intentionally includes multiple summary options and more bullet points than a normal application resume. It is the controlled source from which I build targeted versions.

## Evidence Bank — 60 Seconds

The experience bank groups bullets by role relevance, while the project bank preserves method and limitation details. The evidence ledger records which claims are validated and what I must be able to explain in an interview.

## Targeted Variants — 90 Seconds

The Data and Business Analytics version emphasizes data validation, Excel workflows, reporting, Shiny, and cross-functional work. The Quantitative Finance and Risk version emphasizes credit-risk screening, probability, factor research, Python, and backtesting. Both versions use only content already present in the master inventory.

## Tracker — 45 Seconds

The tracker connects each application to a target resume version, current status, next action, follow-up date, and interview notes. This makes the resume matrix part of a repeatable job-search workflow.

## Close — 30 Seconds

The main value is not a single resume template. It is the discipline of collecting evidence once, tailoring consistently, and being able to defend every claim.
